# Using the Natural Language API from Google Docs

<h2>📋 Steps</h2>
<ol>
  <li>Navigate to <b>APIs & Services → Credentials</b>.</li>
  <li>Click <b>Create Credentials</b> and select <b>API Key</b>.</li>
  <li>Open the provided <b>Google Docs</b> link from the lab in an <b>Incognito</b> window.</li>
  <li>Paste the required text from the lab into the Google Docs document.</li>
</ol>
